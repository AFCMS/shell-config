# Shell Config

Shell Config installs and configures command-line shells and their prompts for a user account.

## Language

**Shell target**

A shell selected for setup during an installer run. A run can select more than one shell target.

**Managed startup block**

The marked section of a shell startup file that Shell Config owns and can update on a later run.

**Release artifact**

A standalone installer executable or the npm package tarball produced by a Shell Config build and attached to the corresponding GitHub release.
